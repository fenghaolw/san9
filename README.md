# 三国志9 × P社大战略融合版 (San9 Grand Strategy)

一款专注 **PC / Mac 桌面端（高刷 Web 端 + Tauri 原生桌面端）** 的硬核历史大战略沙盘游戏。

本项目采用 **Spec-Driven Development（规范驱动开发，SDD）** 范式构建：所有核心玩法、数值公式、数据结构、多线程引擎架构、三层效用 AI 以及阶段性验收标准，均首先在 [`specs/`](./specs/) 目录下沉淀为可版本化、可追溯、可验证的规范文档，再驱动代码实现与自动化测试。

---

## 核心设计支柱

1. **《三国志9 PK》沙盘骨架：**
   - **全中华一张连续大地图（一枚マップ）**：城池、关隘、港口、山川河流、野外军事设施（`阵/砦/城塞/橹/连弩橹/投石台/石壁/火陷阱`）同处一张无尺寸上限的分块 2.5D 棋盘。
   - **十日一“旬”双阶段循环**：暂停下达宏观指令的 **战略阶段** + 连续推演 10 天（40 Ticks）的 **自动进行阶段**。
   - **五将阵型与兵法联动（`联动`）**：最多 5 将一队（分 `前列/中列/后列` 三排站位），9 大系 38 种兵法自动触发与 2～5 人连锁倍增伤害、伤兵恢复与 **士气归零溃灭**。
2. **《三国志11》大地图内政与武库军备绑定：**
   - 城市领地内建设 `农田/市场/兵舍/锻冶场/厩舍/工房/造船厂`（`Lv1 → Lv3` 全被动产出，告别后期繁琐重复点击，同时可被敌军野战部队袭扰掠夺）。
   - 部队出征阵型绑定城池武库军备（步兵军备、弓弩、战马、攻城器械、大型战船；无军备时可作为 `长蛇` 民兵/输送队出征）。
3. **《维多利亚3 / 欧陆风云5 / 十字军之王3》深度社会与人物机制：**
   - **【EU5 / Vic3】四大真实人口阶层（自耕农 / 世家部曲 / 工匠 / 流民）**：征兵与建筑劳动力开工率直接挂钩，战火催生动态 **流民迁徙**。
   - **【EU5】政令控制度（Control）与东汉世家门阀博弈**：还原汉末颍川荀氏、汝南袁氏、江东顾陆朱张等豪强兼并隐户与君主集权改革（`屯田制 / 唯才是举 / 九品官人`）的张力。
   - **【Vic3】水陆自动军需漕运网**：后方基地的盈余粮草、资金、军备与战马按水陆漕运力自动流向前线重点军镇，免除机械式手动输送。
   - **【CK3】人物深层关系网、性格特质、把柄（Hooks）与战场自主反应**：死敌血战、贪功追击、谨慎重整、把柄策反与储君继承危机。

## Spec-Driven 开发准则 (SDD Workflow)

1. **Spec First（规范先行）：** 任何新系统、数值公式变更或数据结构调整，必须先更新 `specs/` 下对应的规范文档。
2. **Contract Alignment（契约对齐）：** `src/core/types/` 中的 TypeScript 类型定义必须与 [`specs/04-data-schemas.md`](./specs/04-data-schemas.md) 保持 1:1 严格一致。
3. **Deterministic Verification（确定性验证）：** 所有在 `SPEC-01`、`SPEC-02`、`SPEC-03` 中定义的数学公式与状态机，必须配有对应的 Vitest 单元测试。
